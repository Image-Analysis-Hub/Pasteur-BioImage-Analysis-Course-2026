# Whole-Slide Image Analysis with open-source software QuPath

The slides, script and Stardist model we'll use are available in Day3_QuPath folder. The images we'll work with are available at https://zenodo.org/records/18302140, we'll use Colon1.ndpis, Colon1-CY5.ndpi, Colon1-DAPI.ndpi, Colon1-FITC.ndpi, Colon1-TRITC.ndpi, Colon2.ndpis, Colon2-CY5.ndpi, Colon2-DAPI.ndpi, Colon2-FITC.ndpi and Colon2-TRITC.ndpi. You can download and install QuPath at https://qupath.github.io/ and documentation is available at https://qupath.readthedocs.io/en/stable/.
